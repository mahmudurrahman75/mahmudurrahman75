## 👨‍💻 About Me

Hello! I'm **Md. Mahmudur Rahman**, a civil engineer by profession and a web developer by passion, based in **Dhaka, Bangladesh**.

I enjoy combining engineering principles with software development to build practical, scalable, and user-friendly digital solutions. My interests span frontend development, backend systems, and modern web technologies.

- 💻 Develop responsive websites and full-stack web applications.
- ⚛️ Build interactive user interfaces using React and Next.js.
- 🔧 Work with backend technologies such as Laravel and PHP.
- 🧩 Apply analytical thinking and problem-solving to software development.
- 📈 Explore SEO and affiliate marketing.
- 🚀 Continuously learn, experiment, and build meaningful projects.
